# Customer Segmentation Analysis Dashboard

## 📊 Project Overview

This project is a **Customer Segmentation Analysis Dashboard** developed using **Microsoft Power BI**.

The purpose of this project is to analyze customer data and divide customers into different segments based on their **spending behavior, purchase frequency, annual income, and other customer characteristics**.

The interactive dashboard helps businesses understand their customer base and identify different customer groups for better marketing and business decision-making.

---

## 🎯 Objectives

* Analyze customer purchasing behavior.
* Segment customers into meaningful groups.
* Understand spending patterns across customer segments.
* Compare purchase frequency between different segments.
* Analyze the relationship between annual income and customer spending.
* Monitor average order value.
* Analyze customer satisfaction.
* Provide an interactive dashboard for easy business analysis.

---

## 📁 Dataset

The project uses customer-level data containing information such as:

| Feature                     | Description                         |
| --------------------------- | ----------------------------------- |
| Customer_ID                 | Unique identifier for each customer |
| Segment                     | Customer segment/category           |
| Annual_Income_INR           | Annual income of the customer       |
| Total_Spend_INR             | Total amount spent by the customer  |
| Purchase_Frequency_Per_Year | Number of purchases made per year   |
| Avg_Order_Value_INR         | Average value of customer orders    |
| Satisfaction_Score          | Customer satisfaction rating        |

## 📈 Dashboard Components

The dashboard contains several interactive visualizations.

### 1. Customer Segmentation

A donut chart displays the **distribution of customers across different segments**.

### 2. Total Spending by Segment

A clustered column chart compares the **total spending of different customer segments**.

### 3. Purchase Frequency by Segment

A bar chart compares the **purchase frequency per year** across customer segments.

### 4. Income vs Spending Analysis

A scatter chart visualizes the relationship between:

* Annual Income
* Total Customer Spending
* Customer Segment

This helps identify patterns between customer income and purchasing behavior.

### 5. Key Performance Indicators

The dashboard provides summary cards for important customer metrics, including:

* Total Customers
* Total Spending
* Average Order Value
* Customer Satisfaction

### 6. Segment Filter

An interactive slicer allows users to select a specific customer segment and analyze its corresponding data.
